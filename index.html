Cheatsheet

Shortcuts

  • Bold: Cmd/Ctrl+B
  • Italic: Cmd/Ctrl+I
  • Underline: Cmd/Ctrl+U
  • Undo/Redo: Cmd/Ctrl+Z / Cmd/Ctrl+Y
  • Lists: Cmd/Ctrl+Shift+7 / Cmd/Ctrl+Shift+8

Table Actions

  • Click table ellipsis to open table menu.
  • Add/Delete row or column relative to the selected cell.
  • Convert table layout (single column / single row / N columns).

TOC

  • TOC auto-generates from headings `h1`–`h4`.
  • TOC shows hierarchical numbering and previews for images/tables.
